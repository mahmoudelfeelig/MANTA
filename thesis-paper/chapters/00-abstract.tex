\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Mobile and endpoint devices generate continuous traffic across Wi-Fi, cellular, enterprise, and home
networks. Defenders need evidence from this traffic to detect compromise, malware-like behavior,
beaconing, data-exfiltration patterns, and unusual destination changes. Modern traffic is largely
encrypted, so payload inspection is limited and privacy-invasive. Metadata can support threat
detection, but it can also reveal application identity, destination behavior, and user activity.

This thesis implements and evaluates MANTA (Mobile Anomaly and Network Threat Analysis), a
metadata-only framework for encrypted mobile and endpoint traffic monitoring. The objective is to
measure whether Android-computable flow metadata can preserve useful anomaly-detection signal while
reducing the privacy leakage of released telemetry. Here, an anomaly is suspicious network behavior
inferred from flow-level evidence such as timing, direction, volume, novelty, destination change,
burst structure, and per-app baseline deviation. MANTA does not inspect payloads. It converts packet
and flow observations into feature windows for local scoring, privacy-controlled export, and
reproducible machine-learning evaluation.

The implementation combines an Android endpoint, a backend adapter, and an ML pipeline. The
evaluation uses a public-only corpus of 6,034,487 flows from seven dataset sources and 904,371
aggregated 60-second windows. It compares local, backend-assisted, privacy-aware, federated, and
privacy-reduced variants under grouped, source-aware evaluation.

The results show that metadata-only detection is feasible, but strongly dependent on feature and
deployment alignment. In the shared Android adaptive-window comparison, High-recall RF reaches F1
\(0.925\), Privacy RF reaches F1 \(0.910\), Adaptive hybrid RF reaches F1 \(0.895\), the
calibrated backend model reaches F1 \(0.888\), and Low-FPR RF reaches F1 \(0.817\) with fewer false
positives.

The privacy evaluation focuses on two leakage risks. For release leakage, the exported feature
representation is tested. The \texttt{medium} and \texttt{strict} views reduce exact app
re-identification from \(0.282\) normalized app-ID leakage in the full view to \(0.151\) and
\(0.135\), but broader semantic leakage remains high. For observer leakage, a passive on-path observer sees the encrypted traffic sequence before MANTA
applies export-time reductions. That benchmark shows severe leakage: normalized leakage is \(0.544\)
for app ID and \(0.981\) for dataset source. MANTA improves released-telemetry control, not transport-level privacy.
